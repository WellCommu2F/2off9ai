面向 2026 级电子信息本科生的 4–8 年方向选择与行动参考，由 55 页原始 PDF 重排而来的**单文件离线查阅网站**。

## 使用

直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

### 功能

- **左侧目录**：按 册 → 编 → 节 三级折叠，当前章节高亮
- **全文搜索**：标题与正文加权排序，结果带上下文摘要与关键词高亮；快捷键 `/` 聚焦搜索框
- **深浅双主题**：右上角「配色」切换，偏好保存在 localStorage
- **阅读位置记忆**：下次打开自动回到上次读到的章节
- **图片放大**：点击任意插图进入灯箱查看大图
- **打印当前章节**：右上角「打印」，只输出正在阅读的那一节（A4 适配，自动隐藏侧栏/顶栏）
- 阅读进度条、回到顶部、复制本页链接、上一节/下一节翻页

### 文件结构

```
index.html          网站本体（HTML + CSS + JS + 全部正文数据，单文件自包含）
assets/             插图
  research-map.png    Edge AI 研究地图（速查页）
  timeline.png        2026 级关键行动时间轴（速查页）
  fig1-market-size.png   全球 Edge AI 市场规模：四家机构口径对比
  fig2-penetration.png   AI PC 与 GenAI 手机渗透率
  fig3-salary.png        薪资水平
```

> `assets/` 必须与 `index.html` 保持同级，否则插图无法显示。
